One short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock — for the [make.fun One-Liner Laugh Lab bounty](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae).

## Entry

> I didn't eat your sock. I rescued it from the floor — then accidentally filed it under 'dinner.'

(96 characters.)

## How to run

Requires Node 22 or later. The program writes the entry to `/output/entry.txt` (override the directory with `OUTPUT_DIR`):

```sh
node main.ts
```
